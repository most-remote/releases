# MOST — выпуски

Здесь лежат установщики программы MOST (удалённый доступ к компьютерам) и подписанные манифесты обновлений.

- Установщики — в разделе **Releases**, теги вида `v0.0.20`.
- Манифесты каналов `channel-stable` и `channel-beta` читает сама программа: она проверяет подпись издателя, срок действия, размер и контрольную сумму файла до установки.
- Скачивайте только отсюда. Установщик с другого сайта не имеет отношения к проекту.

Пока идёт проверка, выпуски помечены как pre-release и не предназначены для широкой раздачи.
